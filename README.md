# Arabic Slug Fixer

إضافة ووردبريس تحوّل الروابط العربية المشفرة (`%d8%a7%d9%84...`) إلى روابط لاتينية قصيرة ومقروءة، مع تحويل 301 للروابط القديمة.

| قبل | بعد |
|---|---|
| كيف تتعلم البرمجة في ٣٠ يومًا → `/%d9%83%d9%8a%d9%81-%d8%aa%d8%aa.../` | `/ttalm-albrmja-30-ywma/` |

## المزايا
- تحويل تلقائي لروابط المقالات والصفحات والمنتجات والتصنيفات الجديدة.
- حذف التشكيل وكلمات الربط الشائعة (اختياري) وتحديد عدد الكلمات.
- محوّل جماعي للروابط القديمة مع معاينة قبل التنفيذ (50 عنصرًا لكل دفعة).
- تحويل 301 للروابط القديمة: المقالات عبر نواة ووردبريس، والصفحات عبر الإضافة.
- لا تلمس أي رابط موجود إلا بتشغيل المحوّل يدويًا.

## التثبيت
1. ارفع المجلد إلى `wp-content/plugins/` وفعّل الإضافة.
2. أدوات ← Arabic Slugs.

> خذ نسخة احتياطية من قاعدة البيانات قبل التحويل الجماعي.
